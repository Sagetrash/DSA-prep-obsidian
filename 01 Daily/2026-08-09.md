## 💡 Key Learnings Today
* **3Sum (Two Pointers)**: Sorting array $O(N \log N)$ unlocks 2-pointer convergence for two-sum subproblem `-nums[i]`. To achieve optimal $\mathcal{O}(1)$ space, skip duplicate elements directly via pointer iteration rather than allocating an auxiliary `set()`.
* **Longest Substring Without Repeating Characters (Sliding Window)**: Dynamic variable-length window expands right pointer and contracts left pointer via hash set lookup. Total complexity is amortized $\mathcal{O}(N)$ since each index enters/exits set at most once.
* **Container With Most Water (Two Pointers)**: Greedy pointer contraction from outer bounds `low = 0, high = n - 1`. Always shift the pointer with the smaller height, because reducing width can only yield a larger area if the bottleneck height increases. Achieves $\mathcal{O}(N)$ time & $\mathcal{O}(1)$ space.
* **Valid Palindrome (Two Pointers)**: In-place two-pointer scan skipping non-alphanumeric characters (`low += 1` / `high -= 1`) avoids allocating $\mathcal{O}(N)$ extra space for a filtered string. Achieves $\mathcal{O}(N)$ time & $\mathcal{O}(1)$ space.
* **Best Time to Buy and Sell Stock (Sliding Window / Greedy)**: Maintain a running minimum buy price (`min_buy = min(min_buy, price)`) to calculate maximum profit on the fly in $\mathcal{O}(N)$ time & $\mathcal{O}(1)$ space.
* **Squares of a Sorted Array (Two Pointers)**: Compare absolute values at extreme boundaries `left = 0` and `right = n - 1` to fill result array with squared values in $\mathcal{O}(N)$ linear time.
* **Move Zeroes (Fast & Slow Pointers)**: Maintain `slow` pointer for insertion index and iterate `fast` pointer across array to swap non-zero elements into place in $\mathcal{O}(N)$ time & $\mathcal{O}(1)$ space.
* **Remove Duplicates from Sorted Array (Fast & Slow Pointers)**: Maintain `slow` pointer for position of unique values and iterate `fast` to swap new unique numbers forward in $\mathcal{O}(N)$ time & $\mathcal{O}(1)$ space.

## ⚠️ Mistakes & Weaknesses Encountered
* **[[Set Deduplication Overhead]]**: Relying on `set()` data structure to deduplicate triplets instead of in-place pointer skipping (`nums[left] == nums[left-1]`). Increases extra space complexity from $\mathcal{O}(1)$ to $\mathcal{O}(N^2)$.
* **Constraint Inspection / Brute Force Intuition**: Defaulting to nested $\mathcal{O}(N^2)$ loops on stock buying/selling before checking $N \le 10^5$ linear constraints.
