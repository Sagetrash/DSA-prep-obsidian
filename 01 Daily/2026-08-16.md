### 2. [[Balanced Binary Tree]] 🔥 High Value
* **Difficulty**: Easy | **Track**: High Value | **NeetCode #49**
* **Primary Pattern**: [[Trees]]
* **Why Today**: Trees has a 60% hint rate with Grade C on Diameter and Subtree. Balanced Binary Tree directly tests post-order DFS height computation — same cognitive pattern as Diameter. Reinforcement drill.
* **Focus**: For each node, recursively compute height of left and right subtrees. Return early with `-1` as a "sentinel" value if any subtree is already unbalanced (`|left_h - right_h| > 1`). Propagate the sentinel upward.
* **Complexity Target**: $O(N)$ time, $O(H)$ space (call stack depth).
* **Platform Links**: [LeetCode](https://leetcode.com/problems/balanced-binary-tree/) | [NeetCode](https://neetcode.io/problems/balanced-binary-tree)

### 3. [[K Closest Points to Origin]] 📦 Volume
* **Difficulty**: Medium | **Track**: Volume | **NeetCode #66**
* **Primary Pattern**: [[Heap & Priority Queue]]
* **Why Today**: Heap/Priority Queue is at 14.3% module completion (1/7). Consolidate the `heapq` pattern from Last Stone Weight onto a more complex use-case — maintaining a size-K min-heap on Euclidean distance.
* **Focus**: Use `heapq.nsmallest(k, points, key=lambda p: p[0]**2 + p[1]**2)` or manually maintain a max-heap of size K (negate distances for Python's min-heap). No need to take square root — compare squared distances directly.
* **Complexity Target**: $O(N \log K)$ time, $O(K)$ space.
* **Platform Links**: [LeetCode](https://leetcode.com/problems/k-closest-points-to-origin/) | [NeetCode](https://neetcode.io/problems/k-closest-points-to-origin)

### 4. [[Generate Parentheses]] 📦 Volume
* **Difficulty**: Medium | **Track**: Volume | **NeetCode #24**
* **Primary Pattern**: [[Stack]] / [[Backtracking]]
* **Why Today**: Stack module at 42.9% (3/7). Generate Parentheses is the next unsolved problem and introduces **backtracking on stack state** — a critical bridge to the Backtracking module (0/9 unsolved).
