### 1. [[Permutation in String]] 🔥 High Value
* **Difficulty**: Medium | **Track**: High Value | **NeetCode #18**
* **Primary Pattern**: [[Sliding Window]]
* **Focus**: Fixed-size sliding window of size `len(s1)`. Compare character frequency maps (`Counter` or array of size 26) between `s1` and `s2[L:R]`. Slide right by 1, updating char counts in $\mathcal{O}(1)$ time.
* **Complexity Target**: $O(N_2)$ time, $O(1)$ space.
* **Platform Links**: [LeetCode](https://leetcode.com/problems/permutation-in-string/) | [NeetCode](https://neetcode.io/problems/permutation-string)

### 2. [[Lowest Common Ancestor of a Binary Search Tree]] 🔥 High Value
* **Difficulty**: Medium | **Track**: High Value | **NeetCode #52**
* **Primary Pattern**: [[Trees]] / BST
* **Focus**: Leverage BST ordering property: if both `p` and `q` are smaller than `root.val`, LCA is in `root.left`. If both are larger, LCA is in `root.right`. The split point (or matching node) is the LCA!
* **Complexity Target**: $O(H)$ time, $O(1)$ space (iterative).
* **Platform Links**: [LeetCode](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/) | [NeetCode](https://neetcode.io/problems/lowest-common-ancestor-in-binary-search-tree)

### 4. [[Kth Largest Element in a Stream]] 📦 Volume
* **Difficulty**: Easy | **Track**: Volume | **NeetCode #64**
* **Primary Pattern**: [[Heap & Priority Queue]]
* **Focus**: Class implementation (`KthLargest`) maintaining a min-heap of size $K$. On `add(val)`: push `val`, if size $> K$, pop smallest. Return `heap[0]`.
* **Complexity Target**: $O(\log K)$ per `add` call, $O(K)$ space.
* **Platform Links**: [LeetCode](https://leetcode.com/problems/kth-largest-element-in-a-stream/) | [NeetCode](https://neetcode.io/problems/kth-largest-integer-in-a-stream)

### 5. [[Min Cost Climbing Stairs]] 📦 Volume
* **Difficulty**: Easy | **Track**: Volume | **NeetCode #100**
* **Primary Pattern**: [[Dynamic Programming]]
* **Focus**: 1D DP recurrence `dp[i] = cost[i] + min(dp[i+1], dp[i+2])`. Work bottom-up or mutate `cost` array in-place from right to left using 2 scalar variables.
* **Complexity Target**: $O(N)$ time, $O(1)$ space.
* **Platform Links**: [LeetCode](https://leetcode.com/problems/min-cost-climbing-stairs/) | [NeetCode](https://neetcode.io/problems/min-cost-climbing-stairs)
