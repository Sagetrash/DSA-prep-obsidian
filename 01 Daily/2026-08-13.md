## 💡 Key Learnings Today
* **1D Dynamic Programming Recurrence**: `Climbing Stairs` ($dp[i] = dp[i-1] + dp[i-2]$) and `House Robber` ($dp[i] = \max(nums[i] + dp[i-2], dp[i-1])$) demonstrate how decision trees with non-adjacent constraints map into optimal substructure.
* **Kadane's Algorithm (Greedy Subarray Sum)**: Discarding negative prefix sums (`curr_sum < 0 \implies curr_sum = 0`) guarantees that every subarray evaluated starts with a non-negative prefix, achieving $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.
* **Space Optimization**: DP tables storing history can be reduced from $\mathcal{O}(N)$ space to $\mathcal{O}(1)$ space when transitions only dereference $k$ constant preceding states.
