## 💡 Key Learnings Today
* Standard binary search pointer arithmetic `left + (right - left) // 2` prevents integer overflow and handles odd/even length subarrays smoothly.
* Treat $M \times N$ matrix with sorted rows as a virtual 1D array of size $M \cdot N$ using `row = mid // cols` and `col = mid % cols` for $\mathcal{O}(\log(M \cdot N))$ search.
* In binary search on answer space (like [[Koko Eating Bananas]]), return `low` or store `res` when condition holds (`if hours <= h: res = speed`), NEVER return `speed` directly because the final loop iteration may terminate on an invalid speed.
* In rotated sorted array search (like [[Find Minimum in Rotated Sorted Array]]), compare `nums[mid]` against `nums[high]`: if `nums[mid] > nums[high]`, pivot is strictly right (`low = mid + 1`); otherwise `high = mid` (retaining `mid` in search space) with loop condition `while low < high:`.
