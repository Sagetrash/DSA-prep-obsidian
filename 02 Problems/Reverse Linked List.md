## Problem Statement
Given the `head` of a singly linked list, reverse the list, and return the reversed list.

### Examples
```text
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]

Input: head = [1,2]
Output: [2,1]

Input: head = []
Output: []
```

### Constraints
* Number of nodes in list is in range `[0, 5000]`.
* `-5000 <= Node.val <= 5000`
